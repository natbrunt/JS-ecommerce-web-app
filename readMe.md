## JS-Ecommerce-web-app

project is still under construction as this was one of my first projects, however, it has a lot of industry standard vanilla javascript features including magic link and stripeJs

- npm i in each folder
- make note of all .envs
- connect to a local cluster in development is preferable


## Run this project locally
1) `git clone <repo>`
2) `npm i` // npm installation => **nodejs.org** *must run twice in client and server dir*
3) server/ `nodemon` or `node index.js` if nodemon does not work
4) client/ `npm start` // run the client app
